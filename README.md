## Предметна область

Проєкт моделює роботу невеликого інтернет-магазину. Покупець обирає товари та оформлює замовлення, у якому може бути кілька позицій. Замовлення проходить шлях від створення до оплати, відправлення й доставки, а за потреби його можна скасувати. Магазин контролює правила: ціна й кількість мають бути додатними, а оплачене замовлення не можна оплатити вдруге. Код предметної області винесено в окремий проєкт `OnlineStore.Domain`, щоб він не залежав від способу запуску застосунку.
